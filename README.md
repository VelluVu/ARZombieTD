# AR Zombie TD

> An Augmented Reality zombie tower defense game built in Unity.

![Unity](https://img.shields.io/badge/Engine-Unity-black?logo=unity) ![Language](https://img.shields.io/badge/Language-C%23-purple) ![Platform](https://img.shields.io/badge/Platform-AR-brightgreen) ![Type](https://img.shields.io/badge/Type-School%20Project-orange)

## About

**ARZombieTD** is an augmented reality tower defense game developed in Unity. Players place defensive towers in real-world space using AR tracking, and waves of zombies advance toward a target that must be protected. The game combines the classic tower defense genre with mobile AR technology.

## Features

- 📱 Augmented Reality gameplay using Unity AR Foundation or Vuforia
- 🗼 Tower placement on real-world surfaces via AR plane detection
- 🧟 Wave-based zombie enemy spawning
- 🏰 Multiple tower types with different attack ranges and damage
- 💰 Resource management for tower building
- 🌊 Escalating difficulty across waves

## Built With

- **Unity** (3D / AR)
- **C#** — gameplay, tower, and enemy scripting
- **AR Foundation / Vuforia** — augmented reality tracking

## Getting Started

### Prerequisites

- Unity Editor with **AR Foundation** package installed
- An AR-capable mobile device (iOS or Android)
- Xcode (for iOS) or Android Studio (for Android build)

### Running the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/VelluVu/ARZombieTD.git
   ```
2. Open in Unity Hub.
3. Switch build target to **iOS** or **Android** in Build Settings.
4. Build and deploy to a physical device.

## Context

An early exploration of AR development in Unity, applying tower defense game mechanics to an augmented reality context. This project was a stepping stone toward more advanced XR work including the Varjo Mixed Reality template and WebVR experiences.
